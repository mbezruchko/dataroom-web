# План разработки UI для Data Room MVP

Этот документ содержит детализацию создания фронтендовой части на основе Shadcn, Tailwind CSS v4 и React. Мы следуем принципам чистого и профессионального дизайна (SaaS стиль) с акцентом на стабильности и скорости работы.

## 1. Базовый макет (Layout)
- **Цель:** Создать структуру страницы с боковой панелью, шапкой и основным контентом.
- **Компоненты Structure:** 
  - `Sidebar` (слева, фиксированная ширина/сворачиваемый).
  - `Header` (резиновая шапка сверху).
  - `MainContent` (динамическая область с прокруткой).
- **Базовые стили:** Белый/светло-серый фон (`bg-background`), темный сайдбар (опционально) или наоборот. Поддержка светлой и темной тем.

## 2. Навигация (Sidebar & Header)
- **Sidebar:** 
  - Ссылки на секции пространства загрузок (Компании, Финансы, Юридические доки).
  - Список фильтров: Последние, Избранные, Удаленные. 
  - Кнопка "Создать папку / Загрузить файл" (Call to Action).
- **Header:**
  - `Breadcrumbs`: Иерархическая навигация для глубокой вложенности (DataRoom > Finance > ...).
  - Поиск: `Search Input` для фильтрации по файлам текущей папки.
  - Профиль пользователя: `DropdownMenu` с настройками и логаутом (заглушка для UI).

## 3. Файловый менеджер (Main Table)
- **Цель:** Отображение файлов и папок с деталями.
- **Таблица (Table component):**
  - Столбцы: Имя, Размер, Дата изменения, Кто добавил.
  - Разделение иконок: Желтая папка (Folder) и Красная PDF (File Text).
- **Взаимодействия:**
  - Строки кликабельны: Папки открывают вложенный уровень. Файлы открывают `Side Panel` (Sheet).
  - Сортировки по размеру и дате.

## 4. Контекстные действия (ContextMenu & Actions)
- **Быстрые действия:** Hover-эффекты на строках таблицы, которые вызывают инлайн-кнопки (Переименовать, Удалить, Скачать).
- **Модальные окна (Dialogs):**
  - Подтверждение удаления (AlertDialog).
  - Окно переименования (Input).

## 5. Панель свойства файла (Side Panel / Sheet)
- **Цель:** Быстрый просмотр метаданных файла без полного открытия или скачивания.
- **Функционал:**
  - Sheet выезжает справа при клике на файл.
  - Внутри крупная иконка файла или превью, размер, история изменения.
  - Кнопки для скачивания и удаления.

## 6. Загрузка файлов (Upload Zone)
- **Цель:** Механизм добавления новых документов на платформу.
- **Компоненты:**
  - Dropzone поверх основной таблицы (Drag & Drop) или модальное окно.
  - Индикатор загрузки с `Progress Bar` или Spinner'ами.
- **Уведомления:** Toast или Sonner для уведомления об успешной или неудачной загрузке.

## 7. Обработка загрузки и пустых состояний (Skeletons & Empty States)
- **Skeletons:** Заглушки, имитирующие структуру таблицы, пока данные грузятся (например искусственная задержка API).
- **Empty States:** Центрированный пустой блок с иллюстрацией и кнопкой-призывом к загрузке первого документа.
