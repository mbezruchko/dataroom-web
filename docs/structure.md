# 📂 Обзор проекта: Data Room MVP

**Цель:** Создать защищенное хранилище для Due Diligence (аудит перед покупкой компании), где пользователи могут организованно управлять документами.

**Приоритеты оптимизации:**
1. UX/Функционал
2. Робастность/Безопасность
3. Качество кода

---

## 💻 Frontend (React SPA)
Мы используем современный стек для обеспечения скорости и чистоты кода.

### Стек технологий:
- **Framework:** React + TypeScript (Vite) — для типизации и быстрой сборки.
- **Styling:** Tailwind CSS + Shadcn/UI (Slate theme) — для профессионального "SaaS" вида.
- **State Management:** Zustand — для навигации по папкам и UI-состояний.
- **Server State:** TanStack Query (React Query) — для кеширования API-запросов и обработки лоадеров.

### Функциональные модули:

#### Folder Explorer:
- Навигация по вложенным папкам (Breadcrumbs).
- Создание, переименование и рекурсивное удаление папок.

#### File Manager:
- Загрузка PDF-файлов (Drag-and-drop или кнопка).
- Список файлов с метаданными (размер, дата) и превью.
- Переименование и удаление файлов.

#### UX/UI Детали:
- Обработка "пустых состояний" (Empty states).
- Toast-уведомления об ошибках или успешной загрузке.

---

## ⚙️ Backend (FastAPI)
Выбор FastAPI вместо Flask обусловлен необходимостью асинхронной работы с файлами и авто-документации.

### Стек технологий:
- **Framework:** FastAPI — асинхронность для высокой производительности.
- **Database:** PostgreSQL — для хранения метаданных и иерархии папок.
- **ORM:** SQLAlchemy 2.0 (Async) — современный подход к работе с БД.
- **Storage:** Локальная файловая система (папка `/storage`) для хранения PDF.

### Архитектура данных:
- **Таблица `folders`:** `id`, `name`, `parent_id` (Self-reference для вложенности), `created_at`.
- **Таблица `files`:** `id`, `name`, `folder_id` (FK), `file_path`, `size`, `created_at`.
- **Логика удаления:** Каскадное удаление (удаляешь папку — удаляются все вложенные файлы и подпапки).

### API Endpoints:
- `GET /api/nodes/{folder_id}` — получить содержимое текущей директории.
- `POST /api/folders` — создать папку.
- `POST /api/files/upload` — асинхронная загрузка PDF.
- `PATCH /api/nodes/{id}` — универсальный метод переименования.
- `DELETE /api/nodes/{id}` — удаление объекта.

- **Час 5: Integration.** Связка фронта с бэком через React Query, обработка ошибок и лоадеров.
